Connect RobloxForge to your AI

About five minutes. One command sets it up, one more connects your app.

Who makes itIn the terminalDesktop app

Websites (claude.ai, chatgpt.com, gemini.google.com) can't start programs on your computer, so they can't run RobloxForge -- use a terminal or desktop app above.

1Install these first

Python 3.11+python.org · on Windows tick “Add to PATH”
Node.js LTSnodejs.org · runs the Studio bridge
Roblox Studiocreate.roblox.com

2Download and set up RobloxForge


 
No git? Download the ZIP, unzip it, open a terminal in the folder and run the last line.

 
It ends with a list of apps. That means Python, the packages and Node are all fine.





 
 




3Pick your app







4Check it works



 
    
  
  1. Open Roblox Studio and open any place. The first time, restart Studio once -- RobloxForge installs its Studio plugin when it first starts. If Studio asks whether the plugin may connect to localhost, click Allow.
    2. 
  
  2. Ask your AI: 
    Run forge_status
    3. 
  
  3. You want "bridge": "up" and your place listed under "studio". Done -- try “make a lamp post with model_build and show me model_shots”.
    4. 
 





If something's wrong



 
The app doesn't show robloxforgeQuit it completely (desktop apps: also from the tray / menu bar) and reopen. Still missing? Run python connect.py check in the RobloxForge folder -- it should answer with 204 tools.

 
"bridge": "down"Node.js isn't installed, or its first download was blocked. Install Node LTS, reopen the app.

 
Bridge is up but no StudioOpen a place in Studio. After the first run, restart Studio once so it loads the plugin.

 
“Too many tools” or the model gets confusedConnect with fewer tools: add --tools core (95 tools: Studio, instances, scripts, playtests) or pick groups, e.g. --tools core,ui,animation. Group names are on the tool list.

 
Undoconnect.py saves a backup next to every file it changes (.bak-date). Or delete the robloxforge entry from the app's settings.
