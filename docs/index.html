RobloxForge

One MCP server for building Roblox games with an AI agent. Studio control and playtests, modelling with numeric audits, a UI designer with an offline layout engine, animation checks, performance measurement, script sync to disk, Open Cloud -- and offline rendering that keeps working when Studio cannot draw.

155native

GitHubConnect your AIAll tools

A superset

Everything the other Roblox MCP servers offer -- surveyed against six of them -- with the same tool names where they came from.

Won't freeze your playtest

Studio pauses on any eval error, even under pcall. Every input is checked in Python and against the engine's reflection data before Luau runs.

Sees without Studio

A depth-buffered perspective renderer, a UI layout engine and an edit-mode animation sampler: visual checks work on a remote or minimised Studio.

Built on a real game

Prop and in-hand checks, HUD audits, moving-fps tests and seed-pinned A/B profiling came out of shipping one.

Quick start

git clone https://github.com/CosmicCheesee/RobloxForge
cd RobloxForge
python connect.py

Works with Claude Code and Claude Desktop, Codex CLI and the ChatGPT desktop app, Gemini CLI, VS Code Copilot, Cursor, Devin Desktop / Windsurf, Zed and LM Studio. Step-by-step guide for your app →
